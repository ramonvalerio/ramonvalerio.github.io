# Ramon Valerio — Portfolio

Portfólio pessoal construído com React + Vite e Tailwind CSS (dark mode premium).

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura

- `src/components/Hero.jsx` — seção de apresentação imersiva
- `src/components/PortfolioGrid.jsx` — grid de projetos com estado do modal ativo
- `src/components/ProjectCard.jsx` — card individual de projeto
- `src/components/ProjectModal.jsx` — modal de detalhes do projeto
- `src/components/MediaCarousel.jsx` — carrossel de banners/screenshots/vídeo dentro do modal
- `src/components/Footer.jsx` — seção de contato
- `src/data/projects.js` — conteúdo dos projetos (texto e mídias) — substitua pelos projetos reais
